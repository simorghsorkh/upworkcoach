وایرفریم‌های نسخه‌ی 0.1 — «دفتر مربی»

فاز ۲ · ux-designer · ۲۷ مهر ۱۴۰۵ · ایستا، بدون فریم‌ورک و بدون منبع خارجی. یک فایل CSS مشترک (styles.css) با media query برای موبایل (< ۷۶۸px)، تبلت و دسکتاپ (≥ ۱۲۰۰px).

چطور ببینید: هر صفحه را در مرورگر باز کنید و عرض پنجره را تغییر دهید، یا در DevTools حالت دستگاه (مثلاً ۳۹۰px) را بزنید. پنجره‌ها و برگه‌های پایین‌صفحه با لینک‌های «#…» باز می‌شوند (بدون JavaScript). کادرهای زرد خط‌چین «یادداشت طراح» بخشی از محصول نیستند.
