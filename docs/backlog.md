# بک‌لاگ (خارج از MVP)

ایده‌ها و امکاناتی که ارزش دارند ولی فعلاً در دامنه‌ی MVP نیستند. دلیل کامل و شرط بازبینی هر مورد: `docs/02-product/mvp-scope.md` بخش ۴.

| ایده | کی دوباره بررسی شود | پیشنهاددهنده |
|---|---|---|
| نیچ‌یاب AI | بعد از ۳ ماه داده‌ی نیچ و نتیجه از 0.1 و 1.0 | upwork-domain-expert |
| آماده‌سازی مصاحبه با AI | وقتی ≥ ۲۰٪ هنرجوها در مرحله‌ی مصاحبه باشند | upwork-domain-expert |
| پیش‌پاسخ AI برای سؤال‌ها | اگر بار مشاورها از ظرفیت بیشتر شد | product-strategist |
| پیش‌نویس پیام پیگیری | 1.x | upwork-domain-expert |
| rubric اختصاصی Fiverr، Contra، LinkedIn | وقتی ≥ ۲۰٪ اپلای‌ها از پلتفرم دیگری باشند | upwork-domain-expert |
| LMS (ویدئو، آزمون، گواهی) | اگر لینک دادن به محتوا اصطکاک جدی بسازد | product-strategist |
| چت لحظه‌ای و انجمن هنرجوها | بعد از 1.0 | product-strategist |
| ربات کامل تلگرام | اگر نرخ ورود به وب‌اپ پایین بود | product-strategist |
| اپلیکیشن بومی اندروید/iOS | بعد از ۶ ماه | product-strategist |
| جلسه‌ی ویدئویی و رزرو وقت مشاوره | با پکیج مشاوره‌ی پولی | product-strategist |
| پرداخت به مشاورها و گزارش حق‌الزحمه | پس از مشخص شدن مدل پرداخت مشاورها | product-strategist |
| فروش پلتفرم به مربی‌های دیگر (SaaS) | بعد از ۶ ماه، اگر هسته موفق بود | product-strategist |
| داشبورد پیشرفته‌ی کوهورت | 1.0 (F19) و بعد | product-strategist |
| گیمیفیکیشن (امتیاز، نشان، رتبه) | بعد از 1.0 | product-strategist |
| **داشبورد مدیر کل سیستم**: نمای کلی (همه‌ی مربی‌ها با بار کاری و وضعیت هنرجوهایشان، همه‌ی هنرجوها، آمار)، مدیریت تیم، و همه‌ی تنظیمات در یک جا. صفحه‌ی «تیم» (افزودن مربی) جلو کشیده شد | بعد از تست بنیان‌گذار | بنیان‌گذار (۱۴۰۵/۰۸/۰۳) |
| **پرداخت، درگاه، پلن اشتراک و فاکتور** | وقتی بنیان‌گذار مدل دریافت پول را تصمیم بگیرد | بنیان‌گذار (۱۴۰۵/۰۷/۲۷) |
| محاسبه‌گر نرخ و قیمت پروژه | Could در 1.0 | upwork-domain-expert |

**هرگز:** افزونه‌ی مرورگر، اسکرپ و اتصال به API پلتفرم‌ها؛ خدمات اکانت، احراز هویت واسط و نقد کردن درآمد.
